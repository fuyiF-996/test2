# 幸运抛硬币 🪙

一个简单好玩的静态小站点，基于 HTML / CSS / JavaScript 实现，附带本地 Express 启动脚本。核心是一个抛硬币页面，同时藏有一个浪漫的樱花图集彩蛋，以及几个实用小工具。

## ✨ 功能一览

### 1. 幸运抛硬币
- 输入任意正整数，页面会抛出对应数量的硬币。
- 硬币带有 3D 翻转动画。
- 抛完后自动统计正反面数量，并生成饼图展示比例。
- 单次最多支持 50 枚硬币，超过会自动截断。

### 2. 隐藏彩蛋：1314 樱花图集
- 在输入框中输入 `1314` 后触发浪漫过渡：
  - 背景音乐不间断播放。
  - 樱花飘落动画 + 诗句“一生一世，樱你而来。”
  - 后台预加载一张樱花图片，避免进入图集后还在转圈。
- 过渡结束后通过 iframe 展示樱花图集，地址栏同步变为 `/gallery/`。
- 图集内点击“返回抛硬币”可回到首页，音乐不会断开。

### 3. 樱花图集
- 随机展示 `public/图片tr/` 目录下的图片。
- 支持左右切换、随机换图、图片计数。
- 自定义光标图片。

### 4. 实用小工具面板
点击首页“实用小工具”可展开：

| 工具 | 说明 |
| --- | --- |
| 🔮 今日运势 | 从 40 条运势（大吉/中吉/吉/平/凶，各 8 条）中随机抽取一条，含运势导语、宜、忌、小贴士；5 分钟内只能抽一次。 |
| ⏳ 倒计时器 | 设置分/秒，支持开始、暂停、重置。 |
| ⚖️ YES / NO | 随机给出“是 / 否 / 再想想”。 |
| 🎲 随机数字 | 在指定范围内生成随机整数。 |
| ⚖️ BMI 计算器 | 输入身高体重，按中国成人标准给出分类。 |

## 🚀 本地运行

### 环境要求
- Node.js（推荐 18+）

### 启动服务

```bash
node express.js
```

访问：

- 抛硬币首页：`http://localhost:8080/`
- 樱花图集：`http://localhost:8080/gallery/`

Express 会自动把 `public/图片tr/` 映射到 `/images`，因此本地和静态部署都能正常读取图片。

## 🖼️ 如何添加更多图片

1. 把新图片放入 `public/图片tr/` 目录。
2. 更新根目录 `images.json` 和 `public/images.json`，在 `images` 数组里追加新图片的文件名。
3. 刷新页面即可看到新图片被随机展示。

> 支持的格式：`.jpg`、`.jpeg`、`.png`、`.gif`、`.webp`、`.bmp`、`.svg`

## 🛠️ 技术栈

- 前端：原生 HTML5、CSS3、JavaScript（无框架）
- 本地服务：Express.js
- 动画：CSS 3D 变换、关键帧动画
- 图表：CSS `conic-gradient` 饼图

## 📌 注意事项

- 今日运势的 5 分钟冷却时间通过 `localStorage` 记录，刷新页面后仍然有效。
- 背景音乐由抛硬币首页统一管理，进入樱花图集后通过 iframe 加载，确保音乐不中断。
- 输入框做了容错处理，非数字、负数、`0` 都会给出友好提示。
